MARS-09 Odyssey: how the system works

From a real Mars elevation tile to a safe route and ranked science targets, with the uncertainty carried through every step.

HiRISE elevation

Real Mars terrain from NASA

Simulated data

Bands, ice, thermal, noise and gaps

Data stage

Cuts a 256 by 256 grid at 2 m, adds noise and gaps, and keeps a hidden answer key

Perception

Slope and roughness. A Random Forest predicts terrain classes

Uncertainty

50 Monte Carlo runs show how far slope could move

Cost map

Cost with a spread. Steep or missing cells are blocked

Answer key

The truth the planner never sees

Science

Finds targets and ranks them, with intervals

Planner

Risk-aware A*. One dial from bold to cautious

Evaluation

Scores each tile and the science stage

Dashboard

Map, ranked targets, safety badge

Saved result

One file per run, loaded without recomputing

Safety check

Re-checks every route against blocked cells

Only the elevation is real. Every sensor layer is simulated, and the system says so wherever it shows one.
